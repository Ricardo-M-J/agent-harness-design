### Step 5: 构建分层 Prompt（这是核心！）

**按照 image-prompt-engineering SKILL 的 7 层框架，逐层构建英文 prompt。**

```
Layer 1: 审美框架 — 定义视觉语系
Layer 2: 主体概念 — 形态、材质、结构（视觉事实）
Layer 3: 情绪人格 — 可观察视觉特征（非抽象形容词）
Layer 4: 构图视角 — shot type + camera angle + placement + background
Layer 5: 风格技术 — 渲染方式 + 线条品质 + 完成度锚点
Layer 6: 色彩叙事 — 每种颜色有名字+情绪+材质联想
Layer 7: 质量约束 — 具体锚点 + 否定约束
```

**吉祥物 Prompt 构建示例（≥150词）**：

```
Layer 1: Premium minimal vector illustration.
Layer 2: A small floating [角色概念] being — not a robot, not an animal.
[形态描述: 由什么构成、什么形状].
[材质描述: translucent/solid/metallic/organic surface quality].
Layer 3: [可观察情绪特征: large luminous eyes with soft inner glow, subtle warm smile].
[姿态: dynamic yet composed pose, slight upward gaze].
Layer 4: Full body shot, centered, facing forward. Pure white background, generous negative space.
Layer 5: Soft cel-shading with translucent gradients. Clean refined outlines, not cartoonishly thick.
High-end animation studio character sheet quality — polished but not overrendered.
Layer 6: [色彩叙事 — 从 design_paradigm 的色彩视觉翻译展开，每种颜色有名字+情绪+材质联想].
Layer 7: NO TEXT, NO LETTERS, NO NUMBERS, NO WATERMARKS, NO UI FRAMES. 8k equivalent resolution, clean edges, professional quality.
```

**文创产品 Prompt 构建（高对比度和谐版）**：

**核心原则：单一产品焦点 + 背景虚化衬托 + 色彩对比**

```
COLOR & CONTRAST STRATEGY:
- Product: Rich purple #7E3FF2 brand elements (70% of product surface)
- Background: Deep navy #1E3A5F or pure white (20% - strong contrast)
- Accent: ONE vibrant orange #F97316 detail (10% - visual anchor)
- Rule: Product must pop against background, not blend in

VISUAL HIERARCHY:
- Layer 1 (Foreground): Single product, hero shot, 50% of frame
- Layer 2 (Context): Extremely blurred background, color wash only
- Layer 3 (Accent): ONE small high-contrast element draws the eye
```

**Product Photography Prompt:**
```
Premium product photography with STRONG VISUAL CONTRAST.

SUBJECT (Single Focus):
- ONE [product type] only - canvas tote bag OR ceramic mug OR notebook
- Brand logo "{BRAND_NAME}" prominently in rich purple #7E3FF2
- ONE accent element in vibrant orange #F97316 (small but high contrast)
- Clean, uncluttered product surface

BACKGROUND (Strong Contrast):
- Deep navy blue #1E3A5F seamless backdrop OR pure white #FFFFFF
- Extremely blurred, no distinguishable features
- Serves only as contrast to make product pop
- No competing colors or textures

LIGHTING (Dramatic but Clean):
- Single directional key light creating defined shadows
- Rim light to separate product from background
- Reveals material texture without harshness
- Professional studio quality

COMPOSITION (Harmonious Hierarchy):
- Product centered, 40-50% of frame
- Generous negative space around product
- Shallow depth of field: product sharp, background completely blurred
- No secondary props or distractions

COLOR EXECUTION:
- Purple #7E3FF2 (product) vs Navy #1E3A5F (background) = maximum contrast
- Orange #F97316 accent is the ONLY warm highlight
- No competing colors, no color clutter

STYLE: Apple product photography aesthetic, bold contrast, sophisticated minimalism
4K resolution, commercial quality, print-ready
```

**Logo Prompt 构建（高对比度和谐版）**：

**核心原则：70-20-10 色彩法则 + 单一视觉焦点**

```
COLOR STRATEGY (必须遵循):
- 70% Dominant: Deep rich purple #7E3FF2 (紫竹紫) - 品牌主识别色
- 20% Contrast: Deep navy blue #1E3A5F or pure white #FFFFFF - 强对比衬托色
- 10% Accent: Vibrant orange #F97316 (活力橙) - 唯一视觉焦点色

CONTRAST RULES:
- 主色与对比色必须有明度差异 (dark vs light)
- 点缀色必须最亮/最饱和，成为视觉锚点
- 禁止相近色并列 (如紫蓝相邻)
```

**logo_primary** — 品牌主 Logo（高对比度和谐布局）：
```
A professional brand logo design for {BRAND_NAME} with STRONG VISUAL HIERARCHY.

COLOR SYSTEM (70-20-10 rule):
- 70% DOMINANT: Deep rich purple #7E3FF2 for main "{BRAND_NAME}" letters - establishes brand identity
- 20% CONTRAST: Deep navy #1E3A5F background or white #FFFFFF space - creates strong contrast
- 10% ACCENT: Vibrant orange #F97316 for single focal point element only - draws the eye

VISUAL HIERARCHY (must create depth):
- Layer 1 (Foreground): Large bold "{BRAND_NAME}" in metallic purple #7E3FF2, 40% of composition
- Layer 2 (Middle): ONE tech element in orange #F97316 as visual anchor (small but high contrast)
- Layer 3 (Background): Clean dark navy #1E3A5F or pure white, minimal texture

TEXT ELEMENTS (clear hierarchy):
- PRIMARY: "{BRAND_NAME}" - largest, boldest, purple #7E3FF2
- SECONDARY: "{CHINESE_NAME}" - medium size, white or light gray, below main
- TERTIARY: "{ENGLISH_NAME}" - smallest, subtle, below Chinese

CONTRAST REQUIREMENTS:
- Purple #7E3FF2 vs Navy #1E3A5F = high contrast
- Orange #F97316 accent must be the ONLY warm color besides purple
- No competing elements - single focal point only
- Generous negative space around main logo

STYLE: Premium minimalist, Apple/Tesla aesthetic, bold contrast, sophisticated restraint
Ultra high detail, 4K resolution, print-ready quality
```

**logo_icon** — 纯图标（无文字，用于 favicon/app icon）：
```
A minimalist geometric icon derived from the {BRAND_NAME} logo concept.
Abstract symbol representing [品牌核心概念: innovation/intelligence/connection].
Clean simple shapes, flat design, no text, no letters.
Color: {PRIMARY_COLOR} with {ACCENT_COLOR} accent.
Works clearly at 16px, 32px, 64px sizes.
White background, vector quality, scalable.
```
