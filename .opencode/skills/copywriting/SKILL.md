# Copywriting Skill — 创意文案

> 为品牌设计提供专业的创意文案服务。覆盖品牌故事、标语体系、品牌宣言、话术指南等。

---

## 功能

基于品牌定位和设计系统，创作系统化的品牌文案。文案是品牌设计的核心组成部分——好的文案赋予设计灵魂。

---

## 文案类型与模板

### 1. 品牌标语体系 (Tagline System)

```
层次结构：
├── 主标语 (Brand Tagline)：3-7 字，高度凝练
├── 副标语 (Sub-tagline)：8-15 字，解释补充
├── 英文标语 (English Tagline)：对应主标语
├── 品牌口号 (Slogan)：可用于广告/宣传
└── 品牌关键词 (Keywords)：5-8 个核心词汇
```

**质量标准**：
- 主标语精炼有力，3 秒传达品牌核心
- 中英文标语语义对应，不直译
- 避免行业通用套话（"引领未来""创新驱动"）
- 可注册商标（避免过于描述性）

**灵感技法**：
- 品牌名嵌入法：将品牌名中的一个字嵌入标语
- 反差法：对立概念并置（"少即是多"型）
- 动词驱动法：用有力的动作词汇开头
- 问题-答案法：标语暗示解决什么问题

### 2. 品牌故事 (Brand Story)

```
结构：起源 → 使命 → 方法 → 愿景

起源 (Why we exist):
- 创始动机/行业痛点/灵感来源
- 使用具体场景，不空谈

使命 (What we do):
- 一句话描述品牌存在的价值
- 不堆砌形容词

方法 (How we do it):
- 独特的做事方式
- 与竞品的区别

愿景 (Where we're going):
- 对未来的想象
- 宏大的但不虚空
```

**字数建议**：
- 短版：150-200 字（品牌页展示）
- 长版：500-800 字（品牌手册）

### 3. 品牌宣言 (Brand Manifesto)

```
语调：宣言式、有力、富有感染力

结构：
1. 开篇宣言 — "我们相信..."
2. 核心理念 × 3 — 每个理念 3-5 行
3. 行动承诺 — "所以我们将..."
4. 结尾号召 — 一句话收束有力

风格参考：
- Apple "Here's to the crazy ones"
- Nike "If you have a body, you're an athlete"
- Airbnb "Belong anywhere"
```

### 4. 品牌话术/语调指南 (Tone of Voice)

```markdown
## 语调维度

| 维度 | 刻度 | 说明 |
|------|------|------|
| 正式 vs 随意 | [位置] | 用词选择、句式复杂度 |
| 热情 vs 冷静 | [位置] | 感叹号使用、情感词汇频率 |
| 幽默 vs 严肃 | [位置] | 双关/谐音的使用程度 |
| 专业 vs 通俗 | [位置] | 行业术语的使用程度 |

## 文案规则

- 中英文混用规范：何时用英文、何时必须中文
- 数字使用规则：中文数字 vs 阿拉伯数字
- 标点规则：中文全角 vs 英文半角
- 称呼方式：用户/你/您
- 禁用词清单
- 推荐词清单
```

## Anti-AI-Cliché 文案禁令

### 禁止的套话句式
| 禁止 | 原因 |
|------|------|
| "引领未来"、"创新驱动"、"赋能万物" | 每个 AI 生成的品牌都在用 |
| "让XX更简单"、"重新定义XX" | 泛滥的 SaaS 话术 |
| "一站式解决方案" | 毫无信息量 |
| "以用户为中心"、"极致体验" | 空洞无物 |
| "科技改变生活" | 过于泛化 |
| "匠心品质"、"精益求精" | 每个品牌都这么说 |

### 好的文案原则
- **具体而非抽象**："帮 10 万开发者每天节省 2 小时" > "提升开发效率"
- **有个性而非正确**：有态度的文案比四平八稳的文案更有记忆点
- **可验证而非吹嘘**：如果声称某个特性，应该能够证明
- **中文有节奏感**：利用中文的四字格律和韵律

## 文案-设计一致性检查

- [ ] 标语情绪是否与色彩调性匹配？
  - 暖色系 → 适合温暖/活力的文案语调
  - 冷色系 → 适合理性/专业的文案语调
  - 深色系 → 适合高端/克制的文案语调
- [ ] 品牌故事是否与 Logo 理念呼应？
- [ ] 语调指南是否与目标受众匹配？
- [ ] 中英文是否语义对应（非直译）？
- [ ] 是否避免了 AI 套话？
