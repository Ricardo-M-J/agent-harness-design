# 品牌设计技能

## 品牌设计方法论

### 第一步：品牌定位
- 核心价值主张
- 目标受众分析
- 品牌个性定义
- 竞品差异化定位

### 第二步：视觉识别
- Logo 设计（图形标志 + 文字标志）
- 色彩系统（主色 + 辅助色 + 点缀色）
- 字体系统（标题 + 正文 + 英文）
- 图形元素（辅助图形、纹理、图案）

### 第三步：应用规范
- 名片、信纸、信封
- 宣传物料（海报、折页、宣传册）
- 数字媒体（社交媒体头像、Banner）
- 文创产品（帆布袋、马克杯、T恤）

## 色彩心理学参考

| 色调 | 心理感受 | 适用场景 |
|------|---------|--------|
| 蓝色 | 信任、专业、科技 | 科技公司、金融机构 |
| 红色 | 热情、力量、 urgency | 餐饮、运动品牌 |
| 绿色 | 自然、健康、成长 | 环保、教育、农业 |
| 橙色 | 活力、创意、友好 | 创意公司、年轻品牌 |
| 紫色 | 高贵、神秘、创新 | 奢侈品、科技公司 |
| 黑色 | 高端、简约、权威 | 高端品牌、时尚 |
| 金色 | 品质、尊贵、传统 | 高端品牌、传统品牌 |

## 字体选择指南

### 中文标题字体
- 思源黑体（Noto Sans CJK）- 现代简约
- 方正兰亭黑 - 专业商务
- 汉仪旗黑 - 年轻活力
- 站酷高端黑 - 时尚设计

### 中文正文字体
- 思源宋体（Noto Serif CJK）- 优雅正式
- 方正书宋 - 传统经典
- 文泉驿微米黑 - 屏幕阅读

### 英文字体
- Montserrat - 现代几何
- Playfair Display - 优雅衬线
- Inter - 专业无衬线
- Roboto - Google 系统字体

## Logo 设计原则
1. 简洁：能在小尺寸下清晰识别
2. 相关：与品牌行业和调性相关
3. 永恒：避免追随短暂潮流
4. 通用：在各种背景和媒介上都可用
5. 令人记忆：独特且易于记忆
