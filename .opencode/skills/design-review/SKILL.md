# Design Review Skill — 设计评审

> 提供结构化、可操作的设计评审服务。灵感：Open Design 五维自评审 + P0/P1/P2 质量门禁

---

## 功能

识别设计中的问题并给出具体可执行的改进建议（不是模糊的"不够好"），确保设计质量达到交付标准。

---

## 评审框架

### 第一层：五维评分（每维度 1-5 分）

| 维度 | 评估焦点 | 满分标准 |
|------|----------|----------|
| **哲学性** (Philosophy) | 设计理念自洽性、品牌叙事深度 | 每个视觉决策都有理有据 |
| **层级性** (Hierarchy) | 视觉层级、信息架构 | 字号/字重/色彩/间距协同，一眼看到重点 |
| **执行度** (Execution) | 细节打磨、工艺水平 | 像素级精细，间距精确到 4px |
| **特异性** (Specificity) | 差异化、辨识度 | 跳脱行业套路，可一眼识别 |
| **克制感** (Restraint) | 避免过度装饰 | 极简有力，增一分则多 |

### 第二层：AI 套路检测

| 套路 | 表现 | 扣分 |
|------|------|:----:|
| 紫粉蓝渐变 | `#7C3AED → #EC4899 → #3B82F6` | -10 |
| Emoji 图标 | 🚀⚡✨💡🔥 替代专业图标 | -5 |
| 字体懒惰 | Inter/Roboto/Arial 作为唯一字体 | -5 |
| 虚假数据 | "10,000+用户"、"99.9%" | -10 |
| 圆角泛滥 | 所有卡片 >20px border-radius | -3 |
| 左边框卡片 | 彩色 left-border accent card | -3 |
| 假推荐语 | 虚假 testimonials + 圆形头像 | -5 |

### 第三层：P0/P1/P2 质量门禁

**P0 — 任一不通过 = 强制迭代**：
- [ ] 设计系统完整（至少：色彩 + 字体 + 间距）
- [ ] 品牌一致性（所有交付物同色系）
- [ ] Logo 与色彩方案一致
- [ ] 品牌文案存在且合理
- [ ] 无虚假数据

**P1 — 强烈建议**：
- [ ] 色彩提供 oklch 或 HEX+RGB 色值
- [ ] 字体层级 ≥ 4 级
- [ ] 中英文双语考虑
- [ ] ≥ 2 种应用场景
- [ ] 无 AI 套路

**P2 — 加分项**：
- [ ] 动效规范
- [ ] WCAG 无障碍
- [ ] 深色模式
- [ ] 响应式断点

## 改进建议质量标准

### ✅ 好的改进建议
- "主色 #E94560 饱和度过高，与品牌'严谨学术'定位冲突。建议将饱和度降低 20%，从 oklch(55% 0.20 15) 调整为 oklch(55% 0.14 15)"
- "字体层级缺失：当前仅定义了 h1(36px) 和 body(16px)，中间缺少 h2/h3/h4 层级。建议增加 24px/20px/18px 三级，形成 36→24→20→18→16 的完整层级"
- "Logo 安全间距未定义。建议设为 Logo 高度的 25%，并提供错误使用示例（拉伸/变形/颜色替换）"

### ❌ 不好的改进建议
- "设计不够好看" → 太模糊
- "颜色需要调整" → 没说怎么调
- "整体再优化一下" → 没有方向
- "字体可以更好" → 没说哪里不好
